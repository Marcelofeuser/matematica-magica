# Diretrizes pedagógicas e BNCC

- Usar linguagem positiva e evitar punição pelo erro.
- Explicar o raciocínio, não apenas informar o resultado.
- Adequar vocabulário, quantidade de texto e abstração à faixa etária.
- Para 1–3 anos, priorizar contagem visual, comparação e formas, com mediação adulta.
- Para 4–9 anos, avançar de situações concretas para operações e padrões.
- Para 10–15 anos, trabalhar frações, porcentagens, álgebra e geometria em contextos significativos.
- Não afirmar alinhamento formal à BNCC sem revisão pedagógica das habilidades e códigos correspondentes.
- Temas religiosos são opcionais e não alteram o objetivo matemático do desafio.
